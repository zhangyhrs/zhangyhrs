## 👨‍💻 关于我

我主要从事 **自然资源调查与监测、遥感影像智能解译、不动产与自然资源确权登记、大地测量、摄影测量、GIS** 等相关工作，同时关注 **自然资源领域政策法规、技术标准和行业规范**，并结合实际工程业务持续开发 QGIS 插件、GIS 工具和自动化处理程序。
