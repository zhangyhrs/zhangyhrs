My development work focuses on turning practical surveying, mapping, and geospatial workflows into reusable tools using **Python**, **PyTorch**, **QGIS**, **GDAL/OGR**, and related open-source technologies.

我主要从事 **遥感智能解译、GIS、GeoAI、地籍数据库处理与自然资源调查监测**，并持续将实际测绘地理信息业务流程开发为可复用的软件工具、QGIS 插件和自动化处理程序。

## 🧩 QGIS Plugins

- [**GeoStar Selector**](https://github.com/zhangyhrs/GeoStar-Selector-QGIS) — Interactive feature selection and GIS-assisted editing tools for QGIS.
- [**SHP-TXT Converter**](https://github.com/zhangyhrs/SHP-TXT-Converter-QGIS) — Bidirectional conversion between Shapefile geometry and coordinate text data.
- [**DEM DebrisFlow Gradient**](https://github.com/zhangyhrs/DEM-DebrisFlow-Gradient-QGIS) — DEM-based debris-flow channel longitudinal gradient calculation and terrain analysis.

---

## 🛠️ GIS & Surveying Tools

- [**SHP2KMZ Tool**](https://github.com/zhangyhrs/SHP2KMZ_Tool) — Batch conversion of field-survey Shapefiles to KMZ for visualization and field workflows.
- [**Map Tile Downloader**](https://github.com/zhangyhrs/map_tile_downloader) — Multi-source map tile downloading and geospatial imagery management tool.

More tools for **cadastral databases, natural resources registration, remote sensing interpretation, quality inspection, coordinate conversion, document generation, and GIS automation** are under continuous development.
