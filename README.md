<h2 id="about">👨‍💻 关于我</h2>

我主要从事 **遥感智能解译、GIS、GeoAI、地籍数据库处理与自然资源调查监测**，并持续将实际测绘地理信息业务流程转化为可复用的软件工具、QGIS 插件和自动化处理程序。

目前的工作与开发重点集中在 **遥感变化检测与语义分割、自然资源调查监测、地籍数据库处理、空间数据质量检查、QGIS 插件开发以及 GIS 自动化处理** 等方向。

---

<h2 id="research">🧭 研究与开发方向</h2>

- 遥感智能解译与 GeoAI
- 高分辨率遥感影像语义分割与变化检测
- 伪变化抑制、边界增强与多尺度特征融合
- GIS 自动化与空间数据批处理
- QGIS 插件开发与开源 GIS 工具
- 地籍调查、数据库处理与质量检查
- 自然资源调查、监测与确权登记
- 基于 DEM 的地形分析与地质灾害应用
